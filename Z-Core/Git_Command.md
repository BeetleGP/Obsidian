### 1. **Настройка Git**

- `git config --global user.name "Ваше имя"`  
    Устанавливает имя пользователя для коммитов.
- `git config --global user.email "Ваш email"`  
    Устанавливает email пользователя для коммитов.

### 2. **Работа с репозиторием**

- `git init`  
    Инициализирует новый репозиторий в текущей папке.
- `git clone <URL>`  
    Клонирует удалённый репозиторий на ваш компьютер.

### 3. **Работа с изменениями**

- `git status`  
    Показывает состояние репозитория (изменённые, добавленные файлы).
- `git add <файл>`  
    Добавляет файл в область подготовленных изменений.
- `git add .`  
    Добавляет все изменения в области текущего каталога.
- `git commit -m "Сообщение"`  
    Фиксирует изменения с сообщением.
- `git diff`  
    Показывает различия между файлами до и после изменений.

### 4. **Работа с ветками**

- `git branch`  
    Показывает список веток.
- `git branch <имя_ветки>`  
    Создаёт новую ветку.
- `git checkout <имя_ветки>`  
    Переключается на указанную ветку.
- `git switch <имя_ветки>`  
    Альтернативная команда для переключения ветки.
- `git merge <имя_ветки>`  
    Сливает указанную ветку с текущей.

### 5. **Удалённые репозитории**

- `git remote -v`  
    Показывает список удалённых репозиториев.
- `git remote add origin <URL>`  
    Добавляет удалённый репозиторий с именем `origin`.
- `git push`  
    Отправляет изменения в удалённый репозиторий.
- `git push origin <ветка>`  
    Отправляет указанную ветку в удалённый репозиторий.
- `git pull`  
    Загружает изменения из удалённого репозитория и сливает с локальной веткой.
- `git fetch`  
    Загружает изменения из удалённого репозитория без слияния.

### 6. **Работа с историей**

- `git log`  
    Показывает историю коммитов.
- `git log --oneline`  
    История коммитов в кратком формате.
- `git show <хэш_коммита>`  
    Показывает детали указанного коммита.

### 7. **Отмена изменений**

- `git restore <файл>`  
    Отменяет изменения в файле (если они не зафиксированы).
- `git reset <файл>`  
    Убирает файл из области подготовленных изменений.
- `git reset --hard`  
    Отменяет все изменения и возвращает состояние репозитория к последнему коммиту.

### 8. **Теги**

- `git tag <имя_тега>`  
    Создаёт тег на текущем коммите.
- `git tag`  
    Показывает список тегов.
- `git push origin <имя_тега>`  
    Отправляет тег в удалённый репозиторий.

### **Мои заметки** 
- `git -v | --version`
	получаем текущую версию гита
- `git --help | -h`    
	список команд
- `clear` 
	очистить терминал (консоль)
- `ls` 
	(для Mac, Linux (терминал Bash)) показывает список текущих папок 
	(в windows команда -  `dir` (терминал powershell))
- `cd` 
	переход в другую папку (каталог) пример: cd documents/frontend/gulp 
- `cd ..` 
	переход на уровень вверх, выйти из папки 
- `git init` 
	создать репозиторий в той папке которой находишься (создастся скрытая папка .git)
- `git status` 
	что происходит с git , что он отслеживает что нет, работает ли он вообще.
- `git add <name file>` 
	следить за каким-то файлом
- `git add .` 
	следить за всеми файлами в папке
- `git rm --cached <name file>` 
	перестать следить за определённым файлом
- `git commit -m "сообщение..."` 
	фиксируем изменения с сообщением
- файл `.gitignore` 
	в него вписываем все папки и файлы которые не должны попадать в git
	но сам файл .gitignore нужно добавить в отслеживание что-бы гит знал о нём 
	`git add .gitignore` or `git add .`
### **Работа с ветками**
- `git branch` 
	показать ветки
- `git branch <имя ветки>` 
	создаёт ветку
- `git branch -D <имя ветки>`
	удалить ветку
- `git checkout <имя ветки>`
	переключится на ветку которую указываем
- `git checkout -b <имя ветки>`
	создаём ветку и сразу на неё переключаемся
